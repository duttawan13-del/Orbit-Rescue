# Orbit Rescue — ภารกิจกู้ยานอวกาศ

เกมภาษาไทยสำหรับทบทวนระบบสุริยะ ผู้เล่นซ่อมระบบยาน 3 ระบบโดยตอบคำถาม 12 ข้อ สุ่มด่านละ 4 ข้อจากคลังทั้งหมด 18 ข้อ ใช้ภาพพิกเซลที่สร้างขึ้นสำหรับเกมนี้

[เล่นเกม Orbit Rescue](https://orbit-rescue-classroom-n5k8.duttawan13.chatgpt.site/)

## วิธีเล่น
ลงทะเบียนด้วยชื่อ–นามสกุล รหัสนักเรียน ชั้นเรียน และชื่อเล่น ตอบถูกได้ 10 คะแนน สูงสุด 120 คะแนน ไม่มีเวลาจำกัด ตอบครบ 4 ข้อจะปลดล็อกด่านถัดไป จบเกมเมื่อซ่อมครบ 3 ระบบ เป้าหมายการเรียนรู้คือถูกอย่างน้อย 8 ข้อ เหรียญนักบินฝึกหัดให้เมื่อถูก 0–7 ข้อ นักสำรวจอวกาศเมื่อถูก 8–9 ข้อ และผู้เชี่ยวชาญวงโคจรเมื่อถูก 10–12 ข้อ

## โครงสร้าง
- public/game.js จัดการหน้าจอ การลงทะเบียน การตอบคำถาม และการกลับมาเล่นต่อ
- public/orbit.css และ public/*.png รูปแบบหน้าจอและภาพต้นฉบับของเกม
- lib/questions.mjs เนื้อหา เฉลย คำอธิบาย ระดับความยาก คะแนน และวิธีสุ่ม
- lib/mission.mjs ตรวจคำตอบฝั่งเซิร์ฟเวอร์ บันทึกผล และสรุปตารางอันดับ
- app/ หน้าเริ่มต้นและจุดรับคำขอ API
- db/schema.ts และ drizzle/ โครงสร้างฐานข้อมูลและ SQL สำหรับติดตั้ง
- .openai/hosting.json การเชื่อมฐานข้อมูล D1 ใน Sites

## ข้อมูลและการบันทึก
Cloudflare D1 เก็บหนึ่งแถวต่อเที่ยวบิน แยกรหัสนักเรียนออกจากโทเคนลับประจำเที่ยวบิน เบราว์เซอร์เก็บโทเคนเพื่อเล่นต่อ เซิร์ฟเวอร์เก็บเวลาเริ่มและจบเป็น Unix milliseconds รวมถึงเวลาที่เปิดหน้าภารกิจเป็นวินาที เวลาเริ่มและจบใช้คำนวณระยะเวลาตั้งแต่ลงทะเบียนจนจบได้ ระบบบันทึกคะแนน จำนวนข้อถูกและผิด ลำดับคำถาม คำตอบ ด่าน เหรียญ และสถานะหลังตอบทุกข้อ ส่งเวลาเป็นระยะระหว่างเล่น ผู้เล่นคนอื่นอ่านได้เฉพาะชื่อเล่น คะแนน เวลา และอันดับจาก API สาธารณะ สถิติคิดจากเที่ยวบินที่ดีที่สุดของแต่ละรหัส

## ทดสอบบนเครื่อง
ใช้ Node.js 24 และ npm เปิดเทอร์มินัลในโฟลเดอร์ที่แตกไฟล์แล้วทำตามลำดับ

1. ติดตั้งด้วย `npm ci`
2. สร้างแอปด้วย `npm run build`
3. สร้างตารางครั้งแรกด้วย `node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_sweet_red_wolf.sql`
4. เปิดเกมด้วย `npm start` แล้วเปิด URL ที่แสดงในเทอร์มินัล

ฐานข้อมูลทดสอบในเครื่องแยกจากผลนักเรียนบนเว็บไซต์จริง ข้อมูลการเล่นและโทเคนของผู้เล่นไม่รวมอยู่ในซอร์สโค้ด
